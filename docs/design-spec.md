# 격자예보 — 디자인 정리

클로드 디자인이나 다른 도구로 화면을 다시 만들 때 필요한 것만 모았습니다.
데이터·서버·좌표 계산은 이미 동작하므로, 화면만 갈아끼우면 됩니다.

## 한 줄

기상청은 대한민국을 5km 격자로 나눠 예보합니다. 이 서비스는 **그 격자를
블록으로 쌓아 보여주고, 블록 하나를 고르면 그 칸의 예보를 보여줍니다.**

## 왜 격자인가

- 전국 읍면동 3,564곳이 실제로는 **격자 1,625칸**으로 모입니다.
  한 칸에 동이 36개까지 들어갑니다(격자 59,125 — 강남 일대).
- 그래서 "우리 동네 날씨"는 사실 "우리 칸 날씨"입니다. 같은 칸에 든 동네는
  글자 그대로 같은 예보를 받습니다. 이 사실이 이 서비스의 출발점입니다.
- 읍면동 중심점이 없는 칸은 구멍으로 남아서, 내륙 구멍을 메워
  **총 4,083칸**으로 한반도를 빽빽하게 채웁니다. 메운 칸도 실제 격자라
  누르면 예보가 나옵니다.

## 화면 세 덩이

### 1. 지도 + 상태창 (히어로)

```
┌──────────────────────────────────────────────────────┐
│ 격자예보                      [ 동네 이름 ] [현재 위치] │
│                                                       │
│        ▄▟█▙▄                  ┌────────────────────┐ │
│      ▟███████▙                │ 울산광역시 남구 달동 │ │
│     ███████████               │                    │ │
│    ▐████│█████▌  ← 비컨 빔    │    25.4°           │ │
│     ██████████                │ 하늘은 흐림입니다   │ │
│      ████████                 │ 습도 56  바람 4.2  │ │
│       ▜████▛                  │ 강수 없음 오늘21/26│ │
│         ▀▀                    │ 격자 102,84  15시  │ │
│                               └────────────────────┘ │
│  울산광역시 남구 달동                                  │
└──────────────────────────────────────────────────────┘
```

- 지도는 **정면 기울임(2.5D) 투영**입니다. 45° 아이소메트릭은 긴 반도를
  대각선으로 눕혀버려서 한국으로 안 읽힙니다. 가로는 그대로 두고 세로만
  0.66배로 눌러, 한반도가 똑바로 선 채 블록의 윗면과 앞면이 보입니다.
- **블록 높이 = 그 칸의 읍면동 수.** 그래서 서울·부산이 저절로 도심처럼
  솟습니다. 색도 같이 바뀝니다(잔디 → 마른 풀 → 돌 → 콘크리트).
- 고른 칸은 **금블록 + 비컨 빔**. 빔이 하늘까지 올라가서 다른 블록에
  가려도 보입니다.
- 상태창은 지도 위 **우측 상단**(동해 쪽 빈 하늘)에 뜹니다.

### 2. 앞으로 (시간별, 가로 스크롤)

- 한 시간이 **블록 기둥 하나**. 높이는 기온, 기둥에 14px마다 이음선을 넣어
  블록을 쌓은 것처럼 보이게 합니다.
- 낮 기둥은 금색, **밤(19시~06시) 기둥은 보라색**.
- 기둥 위 작은 네모는 하늘 상태: 맑음은 테두리만, 구름많음은 흰 블록,
  흐림은 어두운 블록, 비·눈은 파란 블록.
- 강수확률은 땅바닥 **아래로 매달린** 파란 블록. 비는 떨어지니까.
- 앞 여섯 시간은 초단기예보가 덮은 구간이라 옅게 칠해 표시합니다.

### 3. 날마다 (최대 5일)

마인크래프트 GUI 판 안에 한 줄씩. `요일 · 날짜 / 하늘 / 최저–최고 막대 / 숫자`.
자료가 4시간 미만인 날은 뺍니다(최저·최고가 의미 없음).

## 비주얼 규칙

**서체 — 갈무리(픽셀 비트맵).** 비트맵이라 **지정 크기의 배수에서만 선명**합니다.
이걸 어기면 글자가 뭉개집니다.

| 서체 | 쓸 수 있는 크기 | 쓰는 곳 |
|---|---|---|
| Galmuri9 | 9, 18px | 라벨, 단위, 각주 |
| Galmuri11 | 11, 22, 33, 44px | 본문 |
| Galmuri14 | 14, 28, 56, 84, 112px | 제목, 큰 숫자 |

CDN: `https://cdn.jsdelivr.net/gh/quiple/galmuri/dist/galmuri.css`

**색 — 하늘색은 예보가 정합니다.** `body[data-sky]` 와 `body[data-phase]` 두
속성으로 페이지 전체 팔레트가 바뀝니다. 맑으면 파랗고, 비 오면 가라앉고,
밤이면 어두워집니다.

| 상태 | 하늘 | 글자 |
|---|---|---|
| 맑음 | `#79c0f2` | `#12263a` |
| 구름많음 | `#a0b6c6` | `#19242e` |
| 흐림 | `#8b959d` | `#151b20` |
| 비 | `#5e7484` | `#f0f5f9` |
| 눈 | `#c6dae7` | `#16222c` |
| 밤 | `#131e3a` | `#dbe6f5` |

고정색: 판 `#c6c6c6`, 베벨 밝음 `#f2f2f2` / 어두움 `#5b5b5b`, 테두리 `#1b1b1b`,
금 `#fcc319`, 물 `#2f5fc4`, 잔디 `#7cb24f`.

**판(GUI).** 둥근 모서리 없음, 번지는 그림자 없음. 3px 검은 테두리 +
`inset 3px 3px 0` 밝은 베벨 + `inset -3px -3px 0` 어두운 베벨. 글자 그림자는
흐림 0의 계단식(`3px 3px 0`).

**블록 렌더링 주의.** `shape-rendering: crispEdges` 는 사각형마다 따로
반올림해서 블록 사이에 1px 틈을 남깁니다. 블록을 0.12단위 겹쳐 그려 메웁니다.

## 서버가 주는 것

`GET /api/forecast?nx=<격자X>&ny=<격자Y>`

```jsonc
{
  "observed": {                 // 초단기실황 — 지금
    "temp": 25.4, "humidity": 56, "wind": 4.2, "windDir": 88,
    "pty": 0, "sky": 4, "rain": "0",
    "baseDate": "20260915", "baseTime": "1500"
  },
  "series": [                   // 시간별 66개 안팎
    { "key": "202609151500", "date": "20260915", "hour": 15,
      "temp": 26, "pop": 0, "pty": 0, "sky": 4, "humidity": 56,
      "wind": 4.2, "windDir": 88, "rain": "강수없음",
      "nowcast": true }         // 초단기예보가 덮은 앞 6시간
  ],
  "days": [ { "date": "20260916", "tmn": 19, "tmx": 26 } ],
  "bases": { /* 어느 발표분을 썼는지 */ },
  "source": "kma"               // 실패하면 "sample" + notice
}
```

정확도 순서로 겹쳐 씁니다: **초단기실황 > 초단기예보 > 단기예보.**

`GET /data/places.json` 읍면동 3,564곳 → 격자 + 위경도
`GET /data/cells.json` 격자 4,083칸 `[nx, ny, 동수, 대표동index]` (동수 0 = 메운 칸)

## 코드값

- 하늘상태 SKY — 1 맑음, 3 구름많음, 4 흐림
- 강수형태 PTY — 0 없음, 1 비, 2 비/눈, 3 눈, 4 소나기, 5 빗방울,
  6 빗방울눈날림, 7 눈날림
- ±900 이상은 결측값이라 버립니다.

## 아직 안 한 것

- 좁은 화면(≈430px) 실제 기기 확인. CSS는 넣었지만 눈으로 못 봤습니다.
- 앞서 이야기한 **예보 뒤집힘 알림**과 **예보 채점판**. 지금 구조에
  얹을 수 있게 `bases`(어느 발표분인지)를 응답에 넣어뒀습니다.
